# TEAM_RULES

## Grundprinzip
Chat ist Eingang.
Git ist Wahrheit.
KI ist Beschleuniger.
Mensch ist Freigabeinstanz.

## Pflichtregeln
- Kein relevanter Fix ohne Eintrag
- Kein wiederkehrender Fehler ohne Runbook
- Kein kritischer Vorfall ohne Review
- Keine sensiblen Daten unmaskiert im Wissensarchiv
- Keine automatische Promotion in Standards ohne menschliche Freigabe

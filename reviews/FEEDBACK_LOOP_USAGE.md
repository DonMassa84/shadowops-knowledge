# Feedback Loop Usage

## Pflicht
Nach jedem operativen Task:
- Ergebnis kurz erfassen
- Learning notieren
- Trainingswert markieren, wenn relevant

## Review-Regel
- Draft bleibt Draft ohne Review
- Review entscheidet über Runbook, Known Issue oder Archiv
- Dataset-Export nur nach Gate

## Ziel
Aus Output wird wiederverwendbares Systemlernen.
